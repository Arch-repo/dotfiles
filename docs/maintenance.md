# Maintenance Notes

This repo is the source of truth for the Anto426 Hyprland rice.

## Main Sources

- `.config/anto426/wallpaper_core.c` is the C wallpaper engine for apply/effects, palette extraction, live wallpaper handoff, and core session outputs.
- `.config/anto426/wallpaper_apply.sh` and `.config/anto426/wallpaper_effects.sh` are compatibility wrappers. Set `ANTO426_WALLPAPER_APPLY_IMPL=sh` or `ANTO426_WALLPAPER_EFFECTS_IMPL=sh` to force the old Bash path.
- `.config/anto426/wallpaper_effects_modules.sh` is the background bridge used by the C core for modules that still make sense as shell templates: VSCode, GTK, Qt, Kvantum, Zen, GRUB and SDDM. The C core reloads the visible session first, then starts this bridge with low CPU/I/O priority.
- `.config/anto426/wallpaper_effects.d/palette.sh` is the legacy Bash palette implementation.
- `.config/anto426/wallpaper_effects.d/session_theme.sh` still provides the VSCode module while the C core writes shell, Hyprland, Rofi, Waybar colors, Ghostty, htop and btop themes directly.
- `.config/anto426/wallpaper_effects.d/app_theme.sh` writes GTK, Qt, Kvantum and Zen themes through the module bridge.
- `.config/anto426/wallpaper_effects.d/icon_theme.sh` syncs the dynamic Material Symbols icon overlay from `~/Git/arch/Anto426-material-icons`.
- `.config/anto426/install_archpkg.sh` defines the Arch package set.

## Generated Outputs

These files are generated by the wallpaper engine and should not be edited by hand unless debugging:

- `~/.config/colors/colors.{css,rasi,sh}`
- `~/.config/hypr/conf/theme.generated.conf`
- `~/.config/gtk-3.0/settings.ini`
- `~/.config/gtk-4.0/settings.ini`
- `~/.config/qt5ct/qt5ct.conf`
- `~/.config/qt6ct/qt6ct.conf`
- `~/.local/share/icons/Anto426-Material`
- `~/.config/wlogout/icons/*.svg`

## Regenerate Theme

```bash
~/.config/anto426/wallpaper_effects.sh "$(cat ~/.cache/awww/current-wallpaper.path)"
```

Force the legacy Bash implementation for debugging:

```bash
ANTO426_WALLPAPER_EFFECTS_IMPL=sh ~/.config/anto426/wallpaper_effects.sh "$(cat ~/.cache/awww/current-wallpaper.path)"
ANTO426_WALLPAPER_APPLY_IMPL=sh ~/.config/anto426/wallpaper_apply.sh "$(cat ~/.cache/awww/current-wallpaper.path)"
```

Force the module bridge to block in the foreground while debugging:

```bash
ANTO426_WALLPAPER_CORE_MODULES_SYNC=1 ~/.config/anto426/wallpaper_effects.sh "$(cat ~/.cache/awww/current-wallpaper.path)"
```

## Icon Theme

The local icon theme is named `Anto426-Material`.

The icon source and Arch package live in a separate repository:

```bash
~/Git/arch/Anto426-material-icons
```

The wallpaper engine passes the active palette into that repo's builder, then syncs the rendered freedesktop theme into:

```bash
~/.local/share/icons/Anto426-Material
```

The old external icon theme is intentionally not part of the inheritance chain. The fallback chain is `Adwaita,breeze,hicolor`.

Icon generation is handled by the C core through a delayed low-priority worker because it is the slowest module. The worker stores a palette/style signature in:

```bash
~/.local/state/anto426/icon-theme.signature
```

## HyprQuickPaper

The Quickshell wallpaper selector lives in a separate fork:

```bash
~/Git/arch/hyprquickpaper
https://github.com/Arch-repo/hyprquickpaper.git
```

`wallpaper_select.sh` installs `shell.qml` and `cache.sh` from that checkout when it exists, then generates machine-local `config.json` and `commands.sh` under:

```bash
~/.config/quickshell/hyprquickpaper
```

Keep runtime paths out of the fork; update `config.example.json`, `commands.example.sh`, and the installer instead.

Force icon regeneration:

```bash
ANTO426_ICON_THEME_FORCE=1 ~/.config/anto426/wallpaper_effects.sh "$(cat ~/.cache/awww/current-wallpaper.path)"
```

Disable the C icon worker or remove its startup delay while debugging:

```bash
ANTO426_WALLPAPER_CORE_ICONS=0 ~/.config/anto426/wallpaper_effects.sh "$(cat ~/.cache/awww/current-wallpaper.path)"
ANTO426_ICON_THEME_DELAY=0 ~/.config/anto426/wallpaper_effects.sh "$(cat ~/.cache/awww/current-wallpaper.path)"
```

## Repo Workflow

Before committing:

```bash
rg -n "White[S]ur|white[S]ur|white-[S]ur" .config README.md docs
bash -n .config/anto426/wallpaper_apply.sh .config/anto426/wallpaper_effects.sh .config/anto426/wallpaper_effects_modules.sh .config/anto426/wallpaper_effects.d/*.sh
gcc -std=c11 -O2 -Wall -Wextra -o .config/anto426/wallpaper_core .config/anto426/wallpaper_core.c -lm
git diff --check
```
